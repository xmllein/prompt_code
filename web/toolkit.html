收录与核查方式

这是人工筛选、按场景整理的开源资源导航。腾讯、字节、阿里系的身份以项目官方组织为依据；国外生态和社区移植单独注明维护者。

版本、SDK 约束和许可证快照来自 npm / pub.dev 官方注册表。Flutter 平台标签来自 pub.dev 分析；未返回标签不代表不支持。目录没有逐一安装或编译第三方包。

默认隐藏已归档、暂停或停止维护的资源。超过两年未发布的 pub 包提示「发布较早」，这不等于已停止维护。历史示例不会提供快捷安装。

每项的「适合」「注意」是编辑判断。开源 SDK 与其对接的云服务、商业扩展、地图瓦片或附带字体可能有不同许可和费用。

收藏仅保存在当前浏览器。筛选条件保留在当前页面 URL，可复制地址分享；导出内容为当前筛选到的全部资源 JSON。

Flutter 自带的 Material / Cupertino 组件 也应优先评估，无需添加第三方包。
